# 🤖 AI Voice Chatbot

An intelligent AI-powered voice chatbot built using **Streamlit**, **Hugging Face Inference API**, and **pyttsx3** for real-time text-to-speech responses.

This chatbot supports:

- 💬 Conversational AI chat
- 🧠 Context-aware memory
- 🔊 AI voice responses
- ⚡ Fast Hugging Face inference
- 🎨 Interactive Streamlit UI
- 🧵 Background speech threading

---

# 📌 Features

## ✅ Interactive Chat Interface
Built with Streamlit's modern `chat_message()` and `chat_input()` APIs.

## ✅ Conversational Memory
Maintains full conversation history using Streamlit Session State.

## ✅ AI Text Generation
Uses Hugging Face hosted inference models for intelligent responses.

## ✅ Voice Output
Reads AI responses aloud using `pyttsx3`.

## ✅ Multithreading Support
Speech runs in the background without freezing the UI.

## ✅ Clean UI
Minimal and responsive chatbot interface.
